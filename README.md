# 📅 Bong Calendar
**The Bengali calendar — dates, festivals & holidays at a glance.**

`JavaScript` · `Web App` · `Bengali`

## ✨ Features

- 🗓️ Bengali date view & conversion
- 🎉 Festivals & important days
- 📋 Complete holiday listings
- 🌐 Simple, fast & clean

## 🛠️ Built With

- **JavaScript — calendar logic**
- **HTML/CSS — responsive UI**

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Keshab1997/BongCalendarApp.git
# Install dependencies
npm install
# Start the app
npm run dev
```
